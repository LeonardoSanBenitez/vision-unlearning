# Security Policy

## Supported Versions

Security updates are provided for the actively maintained branch of this project (`dev`).
If you are using an older version, please upgrade to the latest release before
reporting a security issue.

## Reporting a Vulnerability

If you believe you have found a security vulnerability in **vision-unlearning**,
please do not open a public issue.

Report security concerns privately by contacting the maintainers via the email `lsbenitezpereira@gmail.com`, informing:

- A clear description of the issue
- Steps to reproduce it
- Any relevant logs, screenshots, or proof-of-concept details
- The impact you believe the issue may have

If applicable, include the exact version, commit hash, and environment details
where the issue was observed.

## Response Process

After a report is received, the maintainers will:

1. Acknowledge receipt as soon as practical
2. Investigate and validate the report
3. Work on a fix or mitigation if the report is confirmed
4. Coordinate disclosure with the reporter when appropriate

## Responsible Disclosure

Please give the maintainers reasonable time to assess and address the issue
before disclosing it publicly.

## Scope

This policy applies to the vision-unlearning project repository, including its
source code, documentation, and release artifacts.
